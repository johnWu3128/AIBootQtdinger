# QuantDinger 功能文档

本文档按用户视角整理平台功能，便于搭建后逐项验证。

## 1. 仪表盘

仪表盘用于查看账户和策略概览：

- 总资产、收益、胜率、活跃策略数量。
- 最近策略运行状态。
- 组合和市场摘要。
- 系统运行状态入口。

## 2. 行情与图表

平台支持多市场行情和 K 线能力：

- 加密货币行情。
- 股票、指数、外汇、期货等数据源适配。
- K 线周期切换和图表展示。
- 技术指标叠加和指标分析。
- 市场机会、新闻、情绪和热力数据扩展。

实际可用市场取决于当前数据源、网络环境和是否配置对应 API Key。

## 3. AI 分析

AI 分析用于辅助研究和策略构思：

- 单标的快速分析。
- 多模型或多 Provider LLM 配置。
- 市场摘要、机会雷达、策略想法生成。
- 自然语言辅助生成指标或策略代码。
- 分析记忆和反思工作流。

启用前需要在 `backend_api_python/.env` 中配置至少一个 LLM Provider 的 Key。

## 4. 指标系统

指标系统面向技术分析和策略开发：

- 创建和管理指标。
- 使用 Python 编写自定义指标。
- 调用内置指标能力。
- 对指标代码进行质量检查。
- 把指标作为策略信号的一部分。

参考文档：

- `docs/INDICATOR_DEFINITIONS_CN.md`
- `docs/STRATEGY_DEV_GUIDE_CN.md`

## 5. 策略系统

策略系统是平台核心：

- 创建 Python 策略。
- 管理策略参数。
- 启动、停止和恢复策略。
- 查看策略运行日志。
- 支持基于指标、脚本和内置模板的策略。
- 支持网格、DCA、马丁格尔、趋势类等常见策略方向。

建议所有策略先回测，再模拟运行，最后才考虑实盘。

## 6. 回测

回测模块用于验证策略历史表现：

- 选择标的、周期和时间范围。
- 设置初始资金和策略参数。
- 执行回测并查看结果。
- 关注收益、回撤、胜率、交易次数等指标。
- 根据回测结果优化策略参数。

回测结果不代表未来收益，只能作为策略筛选和风险评估依据。

## 7. 快速交易与实盘执行

平台提供快速交易和自动执行能力：

- 手动快速下单。
- 策略信号触发交易。
- 交易所或券商账户连接。
- 持仓、订单和执行结果跟踪。
- 后台待执行订单处理。

实盘交易涉及真实资产风险，应先确认：

- API Key 权限最小化。
- 策略已充分回测。
- 交易数量、杠杆、止损、熔断已设置。
- `AGENT_LIVE_TRADING_ENABLED` 等实盘开关符合预期。

## 8. 投资组合

组合模块用于查看账户整体情况：

- 资产净值。
- 持仓列表。
- 收益曲线。
- 风险暴露。
- 多账户汇总。

## 9. 凭证管理

凭证模块用于保存外部服务连接信息：

- 交易所 API Key。
- 券商连接配置。
- LLM Provider Key。
- 通知渠道配置。

敏感凭证会由后端加密处理，但仍建议在本地私有环境中部署，不要公开 `.env`。

## 10. 通知

平台支持多种通知能力：

- Telegram。
- 邮件。
- SMS。
- Discord。
- Webhook。

可用于策略信号、订单执行、异常告警和组合变化提醒。

## 11. 多用户与运营能力

仓库包含面向产品化运营的能力：

- 多用户。
- OAuth 登录。
- 会员和积分。
- USDT 支付。
- 社区/内容相关接口。

如果只搭建个人量化工作台，可以先关闭或忽略这些能力。

## 12. MCP / AI Agent

QuantDinger 支持 AI Agent 通过 MCP 调用平台：

- 读取行情。
- 管理工作区策略。
- 发起回测。
- 发送通知。
- 在受控权限下访问凭证或交易能力。

建议先使用只读和回测权限，不要一开始给 Agent 开通实盘交易权限。
